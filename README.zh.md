## 这是什么

Turbowarp Android 是一个安卓应用，把 [TurboWarp](https://turbowarp.org) 编辑器**完整打包在应用内**。

打开就能用，不需要联网加载编辑器；作品保存在手机本地，可以随时导出成 `.sb3` 分享给别人。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 离线编辑器 | 编辑器、积木图标、插件页全部内置，断网也能编程 |
| 作品列表 | 卡片式网格，显示缩略图、标题、修改日期 |
| 保存 | 编辑器右上角一键保存，写入手机本地 |
| 导出 | 一键导出 `.sb3` 到系统「下载」文件夹 |
| 分享 | 通过微信、QQ 等应用直接发送 `.sb3` |
| 导入 | 本地 `.sb3` 文件，或 Scratch 作品链接 / ID |
| 重命名 | 主界面菜单改名，编辑器内改名会自动同步回来 |
| 主题 | 8 种预设主题色 + 自定义调色板 |
| 深色模式 | 跟随系统 / 浅色 / 深色，主界面与编辑器同步 |
| 高对比度 | 更强的颜色与边框，方便阅读 |
| 双语 | 简体中文 / English，应用与编辑器一起切换 |

## 主界面

顶部是标题栏，右上角两个按钮：

- **导入**：打开导入弹窗
- **设置**：打开设置页

中间是作品网格，每张卡片显示缩略图、作品名和最后修改时间。卡片右上角的 `⋮` 菜单提供：

| 菜单项 | 作用 |
| --- | --- |
| 导出作品 | 把 `.sb3` 保存到系统「下载」文件夹 |
| 重命名 | 修改作品名 |
| 分享 | 把 `.sb3` 分享出去 |
| 删除 | 删除作品（会二次确认） |

右下角的 `+` 按钮新建作品，直接进入编辑器。

## 编辑器

编辑器就是 TurboWarp 本体，并针对手机做了一点调整：

- **顶栏不再有额外的一条红色标题栏**，全部空间留给编辑器
- **右上角是应用的「保存」按钮**，替代 TurboWarp 原来的「保存到文件」
- 已移除用不到/不适用的菜单项：`保存到文件`、`另存为`、`打包作品`、`查看作品页面`、`TurboWarp 反馈`
- **作品名输入框**（菜单栏中间）会显示当前作品名；在这里改名，回到主界面卡片会同步更新
- **插件页**已完整内置，点「插件」正常打开，返回键回到编辑器而不是退出

## 导入与导出

**导入**（顶部 ⤓ 按钮）有两个选项：

1. **从此设备中导入** —— 选择一个 `.sb3` 文件，导入后自动打开，作品名取自文件名
2. **从 Scratch 上导入** —— 填作品链接或 ID（例如 `https://scratch.mit.edu/projects/104/` 或 `104`）
   - 通过 TurboWarp 的中转接口获取项目数据
   - 下载到的项目 JSON 会自动打包成 `.sb3` 保存
   - **注意**：这类作品的造型与声音仍然从 Scratch 官方 CDN 在线加载，第一次打开需要联网

**保存**：编辑器右上角「保存」，作品写入应用私有目录，主界面立刻更新缩略图与时间。

**导出**：主界面卡片菜单 → 导出作品，文件保存到「下载」文件夹，文件名即作品名。

**分享**：卡片菜单 → 分享，选择微信 / QQ 即可发送 `.sb3`。

## 安装

1. 来到 [发布页面](https://github.com/Toushou-114514/Turbowarp_Android/releases/latest) 中
2. 下载 `turbowarp_android.apk` 文件
3. 点击安装
4. 打开应用即可使用

升级时直接覆盖安装，**不会丢失已有作品**。

## 常见问题

**编辑器打开很慢或白屏？**
首次启动需要解压内置资源。如果一直白屏，请把系统里的 Android System WebView 更新到最新版本。

**从 Scratch 导入的作品，角色是空白的？**
图片和声音是从 Scratch 官方 CDN 在线下载的，请检查网络。工程本身（积木、变量）已经保存在本地，联网后会正常显示。

**导出失败？**
Android 9 及以下需要存储权限，请在系统设置里给应用开启存储权限。

**分享时找不到微信 / QQ？**
先在微信里随便发送一次文件，系统才会把该应用登记为文件接收方。

**界面语言和编辑器语言不一致？**
在设置里把语言明确选成「中文」或「English」，不要用「跟随系统」。

## 已知限制

- 造型 / 声音素材库、扩展、从 Scratch 导入的作品素材需要联网
- 不支持云同步、账号登录、在线发布作品
- 作品保存在应用私有目录，卸载应用会一并删除，请及时导出备份
- 目前没有平板专用布局，大屏上会自动排更多列

## 开发者：构建与结构

项目**不使用 Gradle**，通过构建工具链直接打包（aapt2 → javac → d8 → zipalign → apksigner），无 AndroidX 依赖，纯 Framework API。

**构建依赖**

- JDK 8+
- Android SDK Build-Tools 34.0.0
- Android SDK Platform 34（`android.jar`）
