## 這是什麼

Turbowarp Android 是一個 Android 應用程式，把 [TurboWarp](https://turbowarp.org) 編輯器**完整打包在應用程式內**。

打開就能用，不需要連網載入編輯器；作品儲存在手機本機，隨時可以匯出成 `.sb3` 分享給別人。

## 功能一覽

| 功能 | 說明 |
| --- | --- |
| 離線編輯器 | 編輯器、積木圖示、外掛頁面全部內建，斷網也能寫程式 |
| 作品清單 | 卡片式網格，顯示縮圖、標題、修改日期 |
| 儲存 | 編輯器右上角一鍵儲存，寫入手機本機 |
| 匯出 | 一鍵匯出 `.sb3` 到系統「下載」資料夾 |
| 分享 | 透過微信、QQ 等應用程式直接傳送 `.sb3` |
| 匯入 | 本機 `.sb3` 檔案，或 Scratch 作品連結 / ID |
| 重新命名 | 主畫面選單改名，編輯器內改名會自動同步回來 |
| 主題 | 8 種預設主題色 + 自訂調色盤 |
| 深色模式 | 跟隨系統 / 淺色 / 深色，主畫面與編輯器同步 |
| 高對比度 | 更強的色彩與邊框，方便閱讀 |
| 雙語 | 简体中文 / English，應用程式與編輯器一起切換 |

## 主畫面

上方是標題列，右上角兩個按鈕：

- **匯入**：開啟匯入對話框
- **設定**：開啟設定頁

中間是作品網格，每張卡片顯示縮圖、作品名稱與最後修改時間。卡片右上角的 `⋮` 選單提供：

| 選單項目 | 作用 |
| --- | --- |
| 匯出作品 | 把 `.sb3` 存到系統「下載」資料夾 |
| 重新命名 | 修改作品名稱 |
| 分享 | 把 `.sb3` 分享出去 |
| 刪除 | 刪除作品（會再次確認） |

右下角的 `+` 按鈕新增作品，直接進入編輯器。

## 編輯器

編輯器就是 TurboWarp 本體，並針對手機做了一點調整：

- **頂端不再有額外的一條紅色標題列**，全部空間留給編輯器
- **右上角是應用程式的「儲存」按鈕**，取代 TurboWarp 原本的「儲存到檔案」
- 已移除用不到 / 不適用的選單項目：`儲存到檔案`、`另存新檔`、`打包作品`、`查看作品頁面`、`TurboWarp 意見回饋`
- **作品名稱輸入框**（選單列中間）會顯示目前作品名稱；在這裡改名，回到主畫面卡片會同步更新
- **外掛頁面**已完整內建，點「外掛」可正常開啟，返回鍵回到編輯器而不是離開

## 設定

| 設定項目 | 可選值 |
| --- | --- |
| 主題色 | 8 種預設色，或點最後的 `+` 用調色盤自訂（R/G/B 滑桿） |
| 深色模式 | 跟隨系統 / 淺色 / 深色 |
| 高對比度 | 開 / 關 |
| 語言 | 跟隨系統 / 中文（僅簡體） / English |
| 關於 | 版本號、作者、GitHub 儲存庫 |

主題色、深色模式、高對比度、語言會**同時套用到主畫面與編輯器**。

## 匯入與匯出

**匯入**（頂端 ⤓ 按鈕）有兩個選項：

1. **從此裝置匯入** —— 選擇一個 `.sb3` 檔案，匯入後自動開啟，作品名稱取自檔名
2. **從 Scratch 匯入** —— 填作品連結或 ID（例如 `https://scratch.mit.edu/projects/104/` 或 `104`）
   - 透過 TurboWarp 的中轉介面取得專案資料
   - 下載到的專案 JSON 會自動打包成 `.sb3` 儲存
   - **注意**：這類作品的造型與音效仍然從 Scratch 官方 CDN 線上載入，第一次開啟需要連網

**儲存**：編輯器右上角「儲存」，作品寫入應用程式私有目錄，主畫面立刻更新縮圖與時間。

**匯出**：主畫面卡片選單 → 匯出作品，檔案存到「下載」資料夾，檔名即作品名稱。

**分享**：卡片選單 → 分享，選擇微信 / QQ 即可傳送 `.sb3`。

## 安裝

1. 前往 [發佈頁面](https://github.com/Toushou-114514/Turbowarp_Android/releases/latest)
2. 下載 `turbowarp_android.apk` 檔案
3. 點擊安裝
4. 開啟應用程式即可使用

升級時直接覆蓋安裝，**不會遺失已有作品**。

## 常見問題

**編輯器開啟很慢或白屏？**
首次啟動需要解壓縮內建資源。如果一直白屏，請把系統裡的 Android System WebView 更新到最新版本。

**從 Scratch 匯入的作品，角色是空白的？**
圖片和音效是從 Scratch 官方 CDN 線上下載的，請檢查網路。專案本身（積木、變數）已經存在本機，連網後會正常顯示。

**匯出失敗？**
Android 9 以下需要儲存權限，請在系統設定裡給應用程式開啟儲存權限。

**分享時找不到微信 / QQ？**
先在微信裡隨便傳送一次檔案，系統才會把該應用程式登記為檔案接收者。

**介面語言和編輯器語言不一致？**
在設定裡把語言明確選成「中文」或「English」，不要用「跟隨系統」。

## 已知限制

- 造型 / 音效素材庫、擴充功能、從 Scratch 匯入的作品素材需要連網
- 不支援雲端同步、帳號登入、線上發佈作品
- 作品存在應用程式私有目錄，解除安裝會一併刪除，請及時匯出備份
- 目前沒有平板專用版面，大螢幕上會自動排更多欄

## 開發者：建置與結構

專案**不使用 Gradle**，透過建置工具鏈直接打包（aapt2 → javac → d8 → zipalign → apksigner），無 AndroidX 相依，純 Framework API。

**建置相依**

- JDK 8+
- Android SDK Build-Tools 34.0.0
- Android SDK Platform 34（`android.jar`）
